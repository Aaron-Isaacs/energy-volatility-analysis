# Energy Market Volatility Analysis

This project analyses historical price behaviour across major energy commodities using Python statistical modelling. The goal is to identify extreme price movements and connect them to real-world market drivers such as geopolitical events, supply shocks, and demand cycles.

## Features
- Log return calculations
- Volatility analysis
- Extreme event detection (±3σ)
- Multi-market comparison
- Automated CSV reporting
- Visualisations

## Markets Analysed
- Dutch TTF Gas
- WTI Crude
- Jet Fuel
- Heating Oil
- Natural Gas

## Key Insight
Extreme price movements consistently align with macroeconomic and geopolitical shocks, demonstrating the explanatory power of statistical volatility analysis in commodity markets.
